# 内容后端与人工审核

本批承接会员与管理核心。保持原生小程序和 Django 5.2 / Django Ninja，将内容从进程内示例迁移到数据库，并让负责人、内容编辑员通过管理页面维护。变更保留在本地分支 `Jiarui/planning-alignment`。

## 公开内容

- 活动：最新活动、资讯、回顾，列表搜索与分页、详情、时间、地点、公众号链接；草稿默认不公开。
- 商家：分类、地区、介绍、优惠条件、坐标、附近直线距离排序；下架后从列表、详情、精选和相关轮播中消失。
- 首页：轮播、精选商家；轮播不能指向未发布或已隐藏的对象。
- 手册与联系：章节顺序、正文、官方网站和小助手微信号。未配置的联系方式返回空值。
- 管理页面的新增/编辑仅允许显式列出的内容字段；发布与下架由编辑人员选择。用户无法通过附加请求字段取得角色或会员资格。

`GET /home`、`/activities`、`/activities/{id}`、`/merchants/filters`、`/merchants`、`/merchants/map`、`/merchants/{id}`、`/support` 为公开接口。搜索、分类、坐标和分页都在服务端校验。商家距离是 Haversine 直线距离，不是导航时间。

## 论坛

论坛阅读不依赖微信登录；只有有效且未禁言的会员能够创建帖子、评论、点赞和举报。官方公告板块还要求负责人或内容编辑员身份。管理角色本身不等于会员资格。

```text
提交文字 → pending（仅作者和内容管理员可见）
                    ↓ 管理后台明确审核
          approved（公开） / rejected（不公开，作者可看原因）
```

- 默认公开列表只展示已审核内容；“我的帖子”包含自己的待审、拒绝记录。
- 帖子、评论接口返回 `moderation_status` 和 `review_note`；前端显示状态，不把“提交”误称为“发布成功”。
- 帖子隐藏、删除或所在板块停用时，不可继续评论或点赞。评论公开数量只统计已审核且未删除的评论。
- 作者可删除自己的帖子、评论；删除使用数据库标记，不物理清除审核与举报证据。
- 点赞按用户/帖子唯一，重复请求不会累加；举报按用户/目标去重，管理人员填写处理结果。
- 管理后台可以审核、拒绝、置顶；直接地址或伪造 POST 也必须具有 `content.manage`。

本批采用人工审核，仅开放文字提交。新图片上传明确不可用，前端不展示上传控件；历史 mock 图片只是静态示例。没有调用真实微信内容安全服务，也不会把定时延迟当成图片审核通过。

## 反馈

登录用户提交意见、问题或商家信息反馈，获得数据库记录编号。后台查看分类、正文、联系方式并保存处理备注与状态；接口有长度限制、提交节流与重复记录抑制。默认 mock 明确告知未实际发送；本地开发身份明确标记反馈仅保存在本机。

## 角色

| 角色                | 会员审核 | 管理员账号 | 内容编辑、论坛审核、反馈处理 |
| ------------------- | -------- | ---------- | ---------------------------- |
| 负责人 owner        | 是       | 是         | 是                           |
| 会员审核员 reviewer | 是       | 否         | 否                           |
| 内容编辑员 editor   | 否       | 否         | 是                           |
| 普通用户            | 否       | 否         | 否                           |

沿用每次请求重新检查启用状态与角色、CSRF、会话和审计日志。没有新增客户端授权入口。

## 数据与运行

`content` 与 `forum` 为两个独立 Django app。迁移在现有会员表上追加表；本地数据在 `server/var/db.sqlite3`，不进入 Git。`seed_content` 和 `seed_forum` 仅在明确启用的开发环境创建示例，不覆盖已有编辑内容、权限或会员状态。

本地操作见 [server/README.md](../../server/README.md)，验收记录见 [本批验证报告](../qa/2026-09-28-content-backend.md)。ModelForm 使用显式字段和模型校验，依据 [Django 5.2 官方说明](https://docs.djangoproject.com/en/5.2/topics/forms/modelforms/)。

## 剩余范围

真实微信/SMTP、PostgreSQL 并发、正式 HTTPS 与真机；附件和头像存储、微信内容安全、账号注销；社团独立目录、OSM/Mapbox、天气汇率、公众号真实文章、正式内容录入及商家防伪核验。它们不因本批本地接口连通而视为完成。
