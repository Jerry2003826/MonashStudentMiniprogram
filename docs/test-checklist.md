# 手动测试清单

> 最新内容与审核实现见[第三批说明](plans/2026-09-28-content-backend.md)，本文保留早期需求和设计背景。

> **会员与权限最新实现：** 见[本地会员后台说明](plans/2026-09-28-membership-backend.md)。邮箱验证改为待审核，禁止自动转移会员；配对登录和管理权限已在本地实现，旧版自动认证/密码后台描述不再适用。

合并 PR 前，在开发者工具里把改动涉及的页面过一遍；发布体验版前，在 iOS 和 Android 真机上各把全部页面过一遍。

假数据模式下验证码是 `123456`，标题、正文、评论或昵称里带「违规」两个字会被拦截。假数据保存在内存里，重新编译后会恢复成初始状态（未认证）。

每个页面除了下面列的功能，还要检查三种情况：数据加载中、接口出错（可以临时让假接口抛错）、没有数据时，页面都有合理的提示，不会白屏或卡住。

## 首页

- [ ] 轮播图自动播放；点「小程序内测开始啦」进入帖子详情，点「合作商家会员折扣上新」进入商家详情，点第三张不跳转
- [ ] 未认证时，会员入口显示「学生认证，免费成为会员」，点击进入认证页
- [ ] 认证后回到首页，入口变成「我的会员卡」，显示会员编号和有效期
- [ ] 精选商家显示 3 家，点击进入对应的商家详情
- [ ] 下拉可以刷新

## 商家列表

- [ ] 默认显示 6 家，滑到底部加载剩下 2 家，之后显示「没有更多商家了」
- [ ] 「分类」和「区域」筛选结果正确，两个条件可以叠加
- [ ] 搜索「蜀香」只剩蜀香小馆，搜「kiwi」能搜到 Kiwi 手机维修（不区分大小写）
- [ ] 没有结果时显示空状态
- [ ] 下拉可以刷新

## 商家详情

- [ ] 图片可以左右滑动，点击后可以放大预览

- [ ] 点地址会打开地图；点「复制」会复制地址，并且不会同时打开地图
- [ ] 未认证时底部按钮是「认证后享受折扣」，认证后变成「出示会员卡」

## 论坛首页

- [ ] 置顶的官方公告排在第一位，其余帖子从新到旧排列

- [ ] 未认证时点「发帖」弹出认证提示，点「去认证」进入认证页

## 发帖

- [ ] 板块列表里没有「官方公告」
- [ ] 没选板块、没填标题或正文时，「发布」按钮不可点
- [ ] 标题超过 50 字时无法继续输入，正文显示字数统计
- [ ] 最多只能添加 9 张图片，图片可以删除；图片上传中「发布」按钮不可点
- [ ] 正文带「违规」时发布失败，并提示原因
- [ ] 发布成功后回到论坛首页，新帖子排在置顶帖后面

## 帖子详情

- [ ] 正文保留换行，图片可以点击放大
- [ ] 自己刚发的带图帖子，马上打开时图片显示「审核中」；大约 5 秒后重新打开，图片恢复正常
- [ ] 点赞和取消点赞后，数字正确变化
- [ ] 发评论后评论出现在列表最后，评论数加 1；带「违规」的评论发送失败
- [ ] 点别人的评论进入「回复 @某人」模式，可以取消回复
- [ ] 长按自己的评论可以删除，长按别人的评论可以回复或举报
- [ ] 右上角「…」可以举报；自己的帖子还可以删除，删除后返回上一页
- [ ] 未认证时点赞、评论、举报都会弹出认证提示

## 学生认证

- [ ] 输入非 `@student.monash.edu` 邮箱时，点「发送验证码」会提示，并且不开始倒计时
- [ ] 发送成功后倒计时 60 秒，倒计时期间不能重复发送
- [ ] 邮箱或验证码不完整时，「完成认证」按钮不可点
- [ ] 验证码错误时提示「验证码错误或已过期」
- [ ] 认证成功后跳到会员卡页
- [ ] 页面底部显示「假数据模式：验证码固定为 123456」（只在开发版出现）
